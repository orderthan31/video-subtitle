# 개발 현황

기준: 2026-09-11. 전체 태스크 완료 목표는 진행 중이다.

## 구현 및 검증

- 실험 비언어 필터의 충돌 처리 보완: 후속 후보가 대사로 재판정돼도 앞서 승인된 겹침 구간이 삭제되는 문제를 테스트로 재현했다. 모든 판정 후 보호 범위와 충돌하는 후보 전체를 철회하고 PCM 계층에서도 보호 우선을 재검사한다. 후보 순서 반전·분리 후보 유지·모순 입력 PCM 보존을 포함해 전체 Python 177개 통과. 실제 모델 검증 전 기본 비활성 및 승인 대기는 유지한다.

- 다중 탭 계정 전환 오류 수정: 공유 로그인 쿠키가 바뀌면 이전 탭의 계정 표시와 다른 계정의 작업 목록이 섞이는 현상을 회귀 테스트에서 재현했다. 웹 요청을 해당 탭이 확인한 세션에 바인딩하여 쿠키 세션과 불일치하면 데이터 반환 전에 401로 차단하고 재로그인을 요구한다. 새 탭의 세션은 폐기하지 않는다. Python 175개·웹 7개·빌드와 실제 두 탭 전환 검증 통과. 실제 음성 전송 승인 대기와 비언어 필터 품질 미검증 상태는 그대로다.

- 전사 전 비언어 필터의 실험 구현 추가: Gemini 오디오 후보 탐지/문맥 재확인, 발화·불확실 구간 거부, 진폭 기반 무음보다 우선하는 발화 보호, PCM/원본 시간 결합 및 Worker 연결. Python 174개 테스트 통과. 실제 음성 전송은 자동 보안 검토에서 시작 전 차단되어 사용자 승인을 요청했으며, 고정 문장을 로컬 TTS로 새로 생성했다. 실제 대사 보존·호흡/기합 제거 품질은 미검증이므로 `VOCALIZATION_FILTER_ENABLED=false`를 유지한다. 이중 비언어 필터 요구사항은 아직 완료가 아니다. [구현 및 검증 대기 기록](vocalization-filter.md) 참고.

- 웹 인증 연결 완료: 초기 세션 확인, 로그인/로그아웃, 쿠키·CSRF 요청, 만료 시 작업실 해제, 지연된 이전 401 무시를 추가했다. Python 165개·웹 7개 테스트 및 빌드 통과. 데스크톱 로그인/새로고침/계정별 목록/작업 취소/로그아웃/서버 세션 폐기 후 재로그인 화면을 확인했다. 별도 실제 HTTP MP4 업로드도 인증 포함 QUEUED까지 검증했다. Docker 인증 환경 변수와 관리 CLI 복사를 연결했지만 컨테이너 실행·HTTPS·모바일·인증 상태 브라우저 파일 업로드/저장 완료는 미검증이다. 아래 인증 API 단독 단계의 웹 연결 미완료 항목은 이 변경으로 대체한다.

[인증 구성](authentication.md) 참고.

- 자막 검토/수정 구현: 선택적 `review_subtitles`로 전사·번역 뒤 AWAITING_REVIEW 대기, 원본/추가 언어 초안 편집 API·버전 충돌 검사·행 추가/삭제·문구/시간 편집·저장·승인 UI를 연결했다. 승인 후 AI 재호출 없이 출력하고 검토 기본 TTL 24시간·취소·용량 예약을 적용한다. Python 149개·웹 4개 테스트/빌드 통과. 실제 Gemini 작업을 브라우저에서 수정·저장·재열기·승인한 뒤 공급자 없이 NVENC 완료, SRT와 번인 프레임에서 변경 확인. [자막 편집 검증](subtitle-review-verification.md) 참고.

- 필터 강도 설정 연결: `audio_filter=off|conservative|strong`을 API·저장·멱등성·웹 선택/재개·Worker에 추가했다. off는 PCM 그대로, 보수적은 기존 10초 무음, strong은 5초 무음부터 정리하며 임계값 -45dB·0.2초 경계 여유는 유지한다. 일반 단어/감탄사는 모두 보존하고 off에서만 명시적 비언어 태그 정리도 끈다. 142개 Python/웹 4개 테스트·빌드 통과. 실제 FFmpeg 41.3초 통제 음성에서 샘플 보존/시간축 검증 및 실제 Gemini·NVENC 처리 완료. **이 설정은 호흡·기합 오디오 판별 모델을 구현한 것이 아니다.** [필터 검증](audio-filter-verification.md) 참고.

Python 137개·웹 4개 테스트/빌드 통과. 실제 Gemini ko/ja/es 작업 `afef5cf324a2436099485aa82a1db79e` 완료, 각 MP4 트랙 재추출 SRT 텍스트/시간 일치 및 추가 4개 파일 HTTP 200 확인. [다중 언어 검증](multilingual-verification.md) 참고.

- 결과 완료 검증 강화: 단일 비디오/오디오, HEVC/hvc1, yuv420p, AAC, 해상도(90도 회전 메타데이터 반영), 재생 시간과 자막 범위·중첩·최대 두 줄을 검사한다. - 영상 분석 후 `4 × 원본 크기 + 2 × PCM 예상 크기 + 1MiB`를 작업 예약으로 저장한다. PCM은 16kHz·모노·16비트로 계산하며 추출본과 전처리 사본을 모두 반영한다. API 다운로드와 `metadata.result_files` 기반 웹 원문/번역 링크를 추가해 기존 작업에는 없는 원문 파일을 표시하지 않는다. 생성·시간 복원·번역 분리·다운로드 회귀 포함 총 81개 테스트 및 웹 빌드 통과. 실제 Gemini→NVENC 작업 `774683ec6cef432c8ecdb0dcf612a2e6`에서 원문 3개 구간과 HTTP 응답, 데스크톱 링크 표시를 확인했다. 보고서: `data/live-smoke/ba0e8282aacd4aae89d32e887cca419f/report.json`.

- STT 겹침 처리를 문장 단위에서 단어 타임스탬프 단위로 변경했다. 각 60초 담당 구간의 단어를 선택한 뒤 문장을 묶으며 무음 제거 경계는 계속 분리한다. 60초 경계 문장의 중복 방지·의도적 반복 보존 등 총 80개 테스트 통과. 실제 합성 음성을 58초에 배치한 Gemini 두 요청에서 기대 단어열이 모두 일치했고 59.4~61.9초 문장이 복원됐다. 재현: `scripts/smoke-transcription-boundary.py --run-live --audio data/stt-smoke.wav --expected-text "Hello Welcome to the subtitle test The weather is sunny today"`. 보고서: `data/transcription-boundary/5d290cd4fae14f378b3adb32113608f1/report.json` (Git 제외).

- FFmpeg 8.0.1 호환 빌드를 SHA-256 검증 후 별도 설치했다. RTX 5070 Ti/591.86에서 128x128 사전 검사의 최소 프레임 크기 오류를 발견해 640x360으로 수정했다. fallback 없이 실제 Gemini 전사·번역→NVENC 번인 MP4 출력·한글 프레임·임시 파일 정리 확인. [GPU 검증 기록](gpu-verification.md) 참고. 회귀 테스트 총 77개 통과. 로컬 `.env`만 호환 경로로 지정했고 드라이버는 변경하지 않았다.

- Worker SIGTERM/SIGINT(Windows SIGBREAK 포함) 처리 추가. 신호 처리기는 종료 플래그만 설정하고, 정상 실행 경로에서 FFmpeg 자식 프로세스 종료·대기와 Gemini 비동기 요청 취소·회수를 수행한다. 현재 작업은 `FAILED` 및 `metadata.interrupted=true`로 원인을 남기고 정리하며 미시작 대기 작업은 보존한다. idle polling도 즉시 깨어난다. 신호·실제 자식 프로세스·대기 중 Gemini 요청 모의 검증 포함 총 76개 테스트 통과. Docker 종료 유예를 60초로 변경했으며 실제 컨테이너 종료 검증은 남아 있다.

- 결과 응답 전송 구간 전체에 다운로드별 OS 잠금을 유지한다. 동일 작업의 MP4/SRT 동시 다운로드는 허용하고, 전송 중 삭제·GC·Worker 실행은 차단한다. Range 206/416, 마지막 응답 블록까지 보호, 연결 취소 시 해제, 별도 프로세스 비정상 종료 후 잠금 회수를 포함해 총 70개 회귀 테스트 통과. 실제 느린 네트워크·모바일 다운로드 검증은 남아 있다.

- Worker 상태 전환과 종료 상태 기록은 상태 잠금 경합 시 최대 30초 재시도한다. 전환 대기 중 취소 요청도 확인한다. 파일 정리는 개별 폴더가 실패해도 나머지를 시도하며 원래 처리 오류와 별도로 `cleanup_pending`/`cleanup_error`를 저장한다. 다음 GC에서 정리를 재시도하고 한 작업의 파일 오류가 뒤 작업의 수집을 막지 않는다. 실제 잠금 경합을 포함한 회귀 테스트 총 63개 통과.

- 실제 브라우저에서 64.7MB 패딩 MP4 업로드·일시정지·새로고침 후 재개, 동명/동일 크기 변조 파일 차단, 완료 필터, 취소·삭제를 검증했다. 두 번의 재개 모두 서버 파일 SHA-256이 원본과 일치했다. 재현 스크립트와 범위는 [브라우저 검증 기록](browser-verification.md)에 정리했다. 실제 AI 처리·다운로드 및 모바일·1~5GB 검증과는 구분한다.

- 업로드 재개 전에 서버에 저장된 전체 prefix를 4MB 이하 블록으로 SHA-256 비교한다. 이름·크기가 같아도 저장된 내용과 다르면 업로드를 중단한다. Web Crypto를 사용하며 전체 파일을 메모리에 올리지 않는다. 검증 중 일시정지와 서버 크기 변경 감지를 포함해 Python 54개·웹 4개 테스트 및 웹 빌드 통과. 브라우저 파일 재선택 통합 검증은 남아 있다.

- 무음 제거로 붙은 경계를 넘지 않도록 STT 요청을 보존 구간별로 분리했다. 60초 분할의 문맥 겹침도 해당 구간 안으로 제한하며 응답 끝 시간의 반올림 오차를 구간 끝으로 제한한다. 20초 무음 전후의 PCM 요청 분리·원본 시간 복원 등 회귀 테스트 포함 총 53개 통과. 실제 긴 음성의 60초 겹침 병합 품질은 별도 검증이 필요하다.

- FFmpeg `out_time_us` 기반 인코딩 단계 진행률을 API metadata와 웹에 연결했다. 파일 끝 4KB만 읽고 약 1초 간격으로 저장한다. 상태 전환 시 진행률을 초기화하며 작업 전체 완료율로 표현하지 않는다.
- 실제 3초 소프트웨어 인코딩에서 중간 진행률 샘플 11개 확인. 자동 테스트 49개 및 웹 빌드 통과. 진행률이 포함된 작업 행의 브라우저 시각 검증은 남아 있다.

- 고아 폴더 GC 추가: UUID 작업 폴더 중 메타데이터가 없거나 손상되고 마지막 수정 후 `ORPHAN_GRACE_HOURS`(기본 2시간)가 지난 폴더를 정리한다. 실행/상태 잠금이 잡힌 폴더와 최근 변경 파일이 있는 폴더는 보존한다. 총 회귀 테스트 45개 통과.

- `MAX_ENCODING_JOBS`(기본 1)로 동일 저장소를 사용하는 Worker의 인코더 검사/출력 동시 수를 제한한다. OS 파일 잠금 슬롯을 사용하며 대기 중에도 취소/heartbeat를 검사한다. 별도 프로세스의 중복 슬롯 획득 방지, 실패 후 반환, 대기 취소 테스트 포함 총 41개 통과. 모든 Worker는 동일한 슬롯 수 설정을 사용해야 한다.

- Dockerfile, 웹 이미지/Nginx 프록시, docker-compose.yml, GPU override, run-web.ps1 및 설치/실행 문서 추가. YAML 파싱과 기존 테스트 36개 통과. Docker 명령이 현재 환경에 없으므로 컨테이너 빌드·기동은 미검증.

- 업로드 수신 블록을 기록하기 전 실제 사용량/최소 여유 공간 검사 추가. 용량 부족 시 HTTP 507을 반환하고 실패한 요청만 롤백한다. 이미 완료된 이전 요청의 파일과 진행률 보존 테스트 포함, 총 36개 통과.

- 업로드 접수 시 실행 중 작업의 예약 용량을 합산하고 공통 잠금 안에서 검사/작업 생성을 수행한다. 초기 예약은 원본 크기의 4배이며 이미 사용한 작업 용량은 중복 계산하지 않는다. 종료 상태의 예약은 해제한다.
- Worker는 heartbeat 주기(약 5초)에 실제 서비스 사용량/최소 여유 공간을 검사한다. 인코딩 중 한도 초과는 작업 실패/프로세스 중단/정리로 이어진다. 총 테스트 34개 통과.
- 용량 정책의 잔여 제한: 4배 예약은 초기 추정치다. 긴 저비트레이트 원본의 PCM 전개 용량 보장, 업로드 수신 중 watermark 검사, 검사 주기 사이의 출력 증가 제한은 추가 보완이 필요하다.

- 자막 줄바꿈/분할: 한글·중문·일문 24자, 기타 42자 기준 최대 두 줄. 긴 문장은 글자 수에 비례해 기존 시간 구간 안에서 나눈다. 겹치는 발화는 텍스트를 병합 후 분할하며, 정밀 화자별 표시와 읽기 속도 검증은 후속 보완이 필요하다.
- Worker 실패 시 미디어 정리, 진행 중 취소, 실행 잠금이 잡힌 작업의 GC 제외, 결과 TTL 보존/만료 삭제 테스트 추가. 총 자동 테스트 30개 통과.

- FFmpeg/FFprobe 9.0.1 프로젝트 도구 설치와 SHA256 검증 완료.
- 7.17초 합성 영상: 실제 전사/번역, HEVC 출력, 한글 번인 프레임 확인, input/work 정리 성공. 최종 MP4 770,553바이트. 실행 보고서: `data/live-smoke/3208d54604204b4281f24baff110f8fd/report.json` (Git 제외).
- GPU는 RTX 5070 Ti, 드라이버 591.86. 설치한 FFmpeg는 NVENC 13.1/드라이버 610 이상을 요구해 GPU 실행 실패. 명시적으로 허용한 libx265 fallback으로 소규모 통합 검증 완료. NVENC 경로는 미검증.
- 회귀 테스트 21개 통과. FFmpeg 실패 로그의 마지막 3KB를 오류에 보존한다.

- 단계별 로컬 Git 커밋 시작: API 기반, Worker, Web을 분리 기록.
- 실제 Gemini 번역 한 문장과 합성 영어 음성 전사 성공. 전사는 `audioTranscriptionConfig.wordTimestamp`로 받은 단어 시간을 문장 단위로 묶는다. 실제 영상 품질/E2E 검증과는 구분한다.

- API 업로드/재개/취소/삭제 및 저장소 보호 회귀 테스트 10개 통과.
- 미디어 프로세스 실행기, 긴 무음 구간 계산, PCM 구간 복사, 시간 매핑, 인코딩 명령 테스트 7개 통과.

- FFprobe 분석, 오디오 추출, 긴 무음 제거, 원본 시간 복원.
- Gemini REST 전사/번역 어댑터: 60초 단위 오디오와 겹침 구간, 응답 검증, 재시도, 요청 취소.
- SRT 생성과 HEVC 번인 출력, 스트림/재생 시간 검증.
- 실행 중 취소 요청, 완료/실패/취소 정리, 결과 TTL, 중단 작업 처리.

## 남은 작업

- 브라우저 결과 다운로드·인코딩 진행률 표시 및 모바일 검증. 업로드·중단·재개·취소·삭제·완료 필터는 64.7MB 패딩 파일로 확인했으며 실제 대용량 성능 검증이 필요하다.
- GPU의 실제 장시간·대용량 성능 및 배포 환경 검증. 로컬 FFmpeg 8.0.1로 소규모 NVENC 경로는 검증했고, 최신 보안 패치를 반영한 배포용 호환 빌드 검토는 남아 있다.
- 실제 긴 음성의 전사 누락·중복, 번역 품질·용어 일관성 검증. 지정한 두 Gemini 모델의 짧은 실제 요청은 성공했다.
- 오디오 단계의 비언어 발성 판별과 보수적 필터링 검증.
- 구현한 자막 분할의 읽기 속도·번역 문장 시간 배분 검증. STT 단어 단위 겹침 처리는 구현·짧은 실제 요청 검증을 마쳤으나, 요청 간 타임스탬프 흔들림·서로 다른 인식 결과·화자 라벨 일관성을 실제 긴 대화로 검증해야 한다.
- 실제 컨테이너 종료 신호 검증 및 상태 저장 자체가 불가능한 장기 장애 복구 보강. 종료 신호 처리·일시적 상태 잠금 경합·파일 정리 재시도·다운로드 도중 TTL/삭제 보호는 구현·회귀 검증했다.
- 용량 검사 사이 출력 증가 제한과 실제 대용량 저장소 부하 검증. 긴 저비트레이트 영상의 PCM 전개 용량 예약은 구현·회귀 검증했다.
- Docker가 있는 환경에서 이미지 빌드·Compose 기동·볼륨 권한·GPU 실행 검증.
- 30~60분/1~5GB 영상 E2E, 모바일 재생/Seek, 자막 싱크와 정리 검증.
- 미구현 후속 범위: 인증. 자막 편집은 최종 출력 전 검토 방식으로 구현했으며 모바일·다중 언어 실제 편집·많은 cue의 페이지 이동 검증과 편집기 내 영상 미리보기는 남아 있다. 필터 강도 설정은 무음 처리/전사 태그 정리에 연결했으나 오디오 비언어 판별 모델에 대한 강도 적용은 해당 모델 구현 이후 필요하다. 다중 번역 언어·작업 이력·해상도 선택·소프트 자막·H.264·원문 SRT·번역 SMI는 구현했으며 모바일 저장 및 플레이어별 호환성 검증은 남아 있다.
